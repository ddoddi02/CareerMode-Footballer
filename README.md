# CareerMode-Footballer

Football Manager와 FC 시리즈 커리어 모드를 섞은 축구 게임. 경기 중에는 **선수 한 명만** 조작한다.

프로토타입 단계다. 아직 게임이 아니라 **가설 하나를 검증하는 장치**다.

---

## 목표

핵심은 **시야 제한**이다. 화면은 선수가 보는 방향만 밝고 나머지는 어둡다. 뒤를 보려면 고개를 돌려야 하고, 고개를 돌리는 동안은 공을 못 본다.

마우스가 곧 머리다 — **WASD는 뛰는 곳, 커서는 보는 곳**이고, 보는 곳이 곧 보이는 것이다.

FM 능력치를 이 시야에 직접 연결하는 것이 목표다.

| 능력치 | 연결되는 것 |
|---|---|
| Vision | 시야각 |
| Anticipation | 잔상 유지 시간 |
| Composure | 압박 시 시야 축소 저항 |

커리어 모드에서 능력치가 오르면 **숫자가 아니라 화면이 실제로 넓어진다.** 그게 만들려는 것이다.

## 검증하려는 것

HUD 좌측 상단의 두 숫자가 이 저장소의 존재 이유다.

```
확인 후    12/18  (67%)
블라인드    4/15  (27%)
```

터치 직전에 수비수를 확인했을 때와 못 했을 때의 성공률. **이 격차가 벌어지면 시야 메커닉이 작동하는 것이고, 붙어 있으면 장식일 뿐이라 설계를 다시 해야 한다.**

## 레퍼런스

| | 가져온 것 |
|---|---|
| Football Manager | 능력치 체계, 커리어 구조 |
| FC 시리즈 커리어 모드 | 경기 중 한 명만 조작, 리시브·터치 규칙 |
| Escape from Duckov | 시야 제한 표현 방식 |

FC의 **조작 배치는 의도적으로 버렸다.** 패드에서는 보는 방향·뛰는 방향·패스 방향이 같은 두 스틱에서 나와 서로 싸운다. 마우스가 그걸 분리한다.

---

## 실행

Unity **6000.4.1f1** (URP 17.4.0) 로 프로젝트를 연 뒤:

```
Assets/_Prototype/Scenes/ScanAndTurnDrill.unity
```

씬은 손으로 편집하지 않는다. 전부 코드로 생성되며, 빌더가 단일 진실 공급원이다:

```
Tools > Football Prototype > Build Drill Scene
```

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시선 = 보이는 범위 · 조준점 |
| E / R / F / C | 패스 / 슛 / 스루패스 / 크로스 |
| Q | 어깨 너머 확인 (홀드) |
| Shift / Space / LeftCtrl | 스프린트 / 몸으로 지키기 / 제자리 고정 |
| G / Tab | 수비 범위·패스 레인 표시 / 시야제한 토글 |
| P | 패스 벤치 — 전원 정지 후 패스만 |
| Backspace | 리셋 |
